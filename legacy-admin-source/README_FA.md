# کدهای سروری و پنل مدیریت قدیمی

این پوشه آرشیو سورس کدهای پنل مدیریت، middlewareهای TanStack Start، Supabase Service Role client و محافظت endpointهای زمان‌بندی‌شده است. این فایل‌ها عمداً بیرون از `src/` قرار گرفته‌اند تا نسخه عمومی SPA آن‌ها را وارد Build مرورگر نکند.

کدها حذف نشده‌اند، اما GitHub Pages قادر به اجرای Server Function، نگهداری امن کلید Service Role یا اجرای Middleware سمت سرور نیست. برای فعال‌کردن پنل مدیریت باید آن را جداگانه به یک Backend امن منتقل و مستقر کنید.
