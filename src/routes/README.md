# Routes

The public GitHub Pages build is a React SPA using TanStack Router file-based routing.
Every route file under this directory is part of the public messenger application.

## Conventions

| File | URL |
| --- | --- |
| `index.tsx` | `/` |
| `auth.tsx` | `/auth` |
| `reset-password.tsx` | `/reset-password` |
| `_authenticated/route.tsx` | Authenticated layout route |
| `_authenticated/chats.tsx` | `/chats` layout |
| `_authenticated/chats.index.tsx` | `/chats/` |
| `_authenticated/chats.$chatId.tsx` | `/chats/:chatId` |
| `_authenticated/contacts.tsx` | `/contacts` |
| `_authenticated/profile.tsx` | `/profile` |
| `_authenticated/settings.tsx` | `/settings` |
| `__root.tsx` | App shell; preserve its `<Outlet />` |

`routeTree.gen.ts` is generated by `@tanstack/router-plugin` from this directory.
Do not place server functions or administrator routes here: GitHub Pages cannot run
server-side handlers. Legacy administrator route sources are kept outside this
folder in `legacy-admin-routes/`.
